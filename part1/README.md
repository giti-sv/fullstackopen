# Part 1 — Introduction to React

Exercises for [Part 1](https://fullstackopen.com/en/part1) of Full Stack Open.

Scaffolded with Vite (`npm create vite@latest part1 -- --template react`).

## Running

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run lint     # oxlint
npm run build    # production build into dist/
```
