# Full Stack Open

My exercise solutions for [Full Stack Open](https://fullstackopen.com/en/) —
University of Helsinki's course on modern web development with React, Node.js,
MongoDB, GraphQL and TypeScript.

## Structure

Each part lives in its own directory with its own `package.json`.

| Part | Topic | Status |
| ---- | ----- | ------ |
| [part1](./part1) | Introduction to React | in progress |

## Running a part

```bash
cd part1
npm install
npm run dev
```

## Notes

Part 3 (programming a server) lives in a separate repository, since it needs its
own repository root for deployment.
